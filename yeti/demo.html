🦊 Yeti Creatures

Embed 3D creatures anywhere with a simple web component.
Drag to rotate, scroll to zoom.

Dog

Dog (auto-spin)

Usage

<!-- Import the component -->
<script type="module" src="yeti-creature.js"></script>

<!-- Use it anywhere -->
<yeti-creature src="animals/dog.json"></yeti-creature>

<!-- With options -->
<yeti-creature
  src="animals/dog.json"
  width="500"
  height="400"
  spin="0.5"
></yeti-creature>

Attributes

src     Path to animal JSON file
width   Canvas width in pixels (default: 400)
height  Canvas height in pixels (default: 300)
spin    Auto-rotate speed (default: 0)
