Tritone Rick

Diabolus in Musica - The Devil's Interval Rick Roll

What is this?

The tritone (augmented 4th / diminished 5th) spans exactly 6 semitones. Medieval theorists called it "diabolus in musica" (the devil in music) and banned it from sacred compositions.

This plays a recognizable melodic pattern harmonized entirely with tritone intervals, creating an unsettling, "evil" version of a familiar tune.
