Jelly Critter — GPU

A "safe copy" reimplementation of the CORE INTERACTION IDEA behind scottstts/Jelly-Baby (wander + hop + grab-drag-throw a soft bouncy creature) — NOT its code, which carries no LICENSE file and so cannot legally be vendored. Everything here is built fresh on this project's OWN, already-existing, UNMODIFIED critter pipeline (lib/critters.js's damped-spring squash-and-stretch physics — the overshoot/jiggle "jelly" feel was already real — and lib/gpu-critter.js's WGSL compute skinning). New in this file only: player control (WASD/ arrows to wander, Space to hop, both camera-relative), drag-to-grab the critter directly (screen-projected hit test, not a raycaster) and throw it (velocity computed from the drag's own recent motion, not a random fling), a live flavor/colour picker, and a translucency slider — a fresnel/rim effect (gpu-critter.js's alphaMult+camPos), not a flat alpha fade: see-through facing the camera, more solid at the silhouette edge, the actual glass/jelly-candy cue. No tabletop world, swing, trampoline, or facilities — this is the bounce mechanic alone.
