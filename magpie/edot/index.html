🟫 edot

A browser office suite — editor, data, slides, calendar, mail and maps — composable over one shared kernel, with a places/geo layer (Wikidata-linked) wired across them.

Composed

🧩
Workspace
live
Data, Slides and Editor in one page over one kernel — a query result flows into a deck and a document with no file. Geo functions in the Data pane.

Apps

✍️
Editor
Rich-text document editor — formatting, find/replace, import/export (DOCX, Markdown, PDF, HTML), GitHub save.
 ▦
Data
SQLite engine, editable grid, Excel-like sheets with formulas (incl. =SQL() and geo functions), N-Quads.
 ▤
Slides
Deck editor with templates, SVG render, present mode.
 📅
Calendar
Month/week/day/agenda, recurrence, reminders, ICS import/export — event location autocomplete with QIDs.
 ✉️
Mail
Composer and mailbox UI.
 🗺️
Maps
3D
MapLibre map with geocode, routing, saved places — plus 3D terrain, 3D buildings and KML/KMZ import.
 ⤓
Backup
Export/restore the suite's local data.
 🔐
Sign in
alpha
The shared sign-in flow (experimental).
