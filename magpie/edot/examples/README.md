# edot — example documents

Sample documents surfaced under **File ▸ Examples** in the editor.

## searching-for-logic.docx
"Searching for Logic" by **Adam Morton** — a complete introductory logic
textbook (≈115,000 words, 100+ tables, embedded figures). Mirrored here so the
Examples menu can load it same-origin (the author's site sends no CORS header,
so a live cross-origin fetch from GitHub Pages would be blocked).

- Source: <https://www.fernieroad.ca/a/> ("Searching for Logic (Morton) Nov 017.docx")
- Author: Adam Morton (<https://www.fernieroad.ca/>)
- Status: freely distributed by the author for educational use. Included here
  only as a demonstration document for the editor. All rights remain with the
  author; remove on request.

It doubles as a real-world stress test of edot's `.docx` importer (tables,
figures, long-document performance).
