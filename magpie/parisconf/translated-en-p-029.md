F. C. WILLIAMS and T. KILBURN

SURVEY OF RESEARCH ON CALCULATING MACHINES

AT THE UNIVERSITY OF MANCHESTER

Active development of calculating machines at Manchester began
in January 1947 with research on memory mechanisms in which an
electrical charge is retained on the screen of a cathode ray tube.
It soon appeared that such a memory could compete honorably with
existing memories, and it was decided to construct a series of
calculating machines with progressively increasing capabilities
using this memory as the basic element.

Since then, three machines have been constructed, all using
the binary system and operating serially using a single-track code.

The first of these machines, in service from June 1948, had
very limited capabilities. It had a total main memory capacity of
32 words of 32 digits long; an accumulator and a single-word
command memory; and a single arithmetic operation, namely
subtraction. Transfer of control could be introduced conditionally
or unconditionally depending on the result of an examination of
the sign of the number in the accumulator. This machine could
perform multiplication, division, and factorization.

The second machine, in service in June 1949, was an extension
of this "baby" machine. It had improved arithmetic operation
capabilities, which include logical operations, addition, and
multiplication; manual input could be performed through an
auxiliary magnetic drum memory. The most characteristic problem
attempted on this machine is a calculation of Mersenne prime
numbers up to the value 2^537 - 1.

## Notes
- F.C. Williams and T. Kilburn were the creators of the Manchester Baby, the first stored-program computer to run a program (June 21, 1948)
- The "Williams tube" memory stored bits as charged spots on a CRT screen
- The "baby" machine (Manchester Small-Scale Experimental Machine) is a landmark in computing history
- 32 words x 32 bits = 1024 bits = 128 bytes of memory
- Mersenne primes (2^p - 1) were a classic test problem for early computers
- [Translation note: "tube a rayon cathodique" = cathode ray tube (CRT); the Williams-Kilburn tube memory was a breakthrough enabling practical stored-program computers]
