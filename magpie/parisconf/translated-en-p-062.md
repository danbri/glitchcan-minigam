## Content

P. PUIG ADAM


LINEAR FEEDBACK CHAIN SYSTEMS AND CONTINUED FRACTIONS


After a brief overview of the formal schematization of correspondences between input and response (input and output) functions of linear physical systems, the author observes that if one takes as the transformation function of a system the quotient between the Laplace transforms of the input function (dividend) and response function (divisor), the transformation function of a simple feedback system takes the form of a step of a continued fraction.

For a set of chained linear control systems such that each of them is controlled by the following one, the total transformation function is expressed by means of a continued fraction whose partial quotients are the transformation functions of the successive feedback circuits. The approximation and convergence procedures of this algorithm suggest possible technical and psychophysiological applications in relation to questions of stability.
