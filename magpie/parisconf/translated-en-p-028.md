# Page 28

## Type
Abstract

## Language
French

## Translation

E. J. PETHERICK

SHORT-CUT MULTIPLICATION IN A

PARALLEL-DECIMAL AUTO-CALCULATOR

The essential features of the relay calculator R.A.E.S.C.C.,
under construction at the Royal Aircraft Establishment, will first
be outlined; then the method used for multiplication will be detailed.
The R.A.E.S.C.C. calculator is a parallel-decimal machine using
a floating decimal point and a three-way control code with perforated
tapes for input and output, magnetic drum memory, and typewriter
printing. Approximately thirty command instructions are available,
and the time required for each operation is at most five seconds -
(in the case of finding a sine or cosine). Particular attention
has been paid to data organization, and the complexity of usable
circuits has been reduced to what pure logic would require.

The circuits are designed to form products by 2, 3, 4 or 5
of any data - or their complements - using no more than six relays
beyond the decimal encoder, the indispensable minimum. The methods
employed for short-cut multiplication and non-restoring division
use these circuits, in conjunction with others intended to determine
which multiple is required at each step of these operations.

## Notes
- R.A.E.S.C.C. = Royal Aircraft Establishment Special Computing Circuit
- RAE at Farnborough was a major British aerospace research establishment
- "Parallel-decimal" indicates digits processed in parallel (fast) but using decimal (not binary) representation
- Floating decimal point was an advanced feature for 1950
- "Short-cut multiplication" refers to optimized algorithms reducing the number of operations
- "Non-restoring division" is an efficient division algorithm still used today
- 5 seconds for sine/cosine calculation reflects relay-based speed limitations
- [Translation note: "multiplication abregee" = short-cut multiplication, referring to algorithms that reduce computational steps through clever use of partial products]
