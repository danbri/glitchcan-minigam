The speed of solving a problem is not enormously affected by
such an arrangement provided that the time taken to transfer
a set of information from the auxiliary memory to the cathode ray
tube memory is small compared to the time taken to use the
transferred information. The magnetic drum is a particularly
convenient means of providing auxiliary memory, thanks to its
compactness and the permanence of the recordings. Furthermore,
if the drum is driven in synchronism with the rhythm of the
cathode ray tube memory, the time for information transfer is
kept to a minimum, and if correct phase is obtained, no difficulty
will arise in identifying the information after transfer because
there exists a one-to-one correspondence between the position of a
digit in memory and its position on the magnetic drum.

The current machine, third in date, which ran for the first
time in January 1950, is the second machine equipped with devices
for recording and reading results on perforated paper tape, and
for automatic control of information transfers between the magnetic
drum and the cathode ray tube memory.

Building on the results obtained with these machines, a machine
plan was conceived in 1949 and the order was placed with Messrs.
Ferranti Ltd. of Moston, Manchester. The capacity of the cathode
ray tube memory of this new machine is 10,240 digits and that of
the magnetic drum memory approximately 16,000 digits with the
possibility of extending it to 650,000. The machine includes an
electronic multiplier, capable of reading and multiplying two
40-digit numbers in less than 4 milliseconds, as well as some other
new capabilities. The time required to read and execute a general
type command (for example "add a 40-digit number to the contents
of the accumulator") is 1.2 milliseconds. This machine has just
entered service.

## Notes
- The Ferranti Mark 1 (commissioned 1949, delivered 1951) was the first commercially available general-purpose computer
- The two-level memory hierarchy (fast CRT + slower drum) anticipates modern cache/RAM architectures
- 10,240 binary digits = ~1.25 KB of fast memory
- 4 milliseconds for 40-bit multiplication and 1.2 ms for instruction execution were fast for the era
- "Biunivoque" (one-to-one correspondence) refers to memory mapping between levels
