Architecture Overview

Lucid is a modular SDF (Signed Distance Function) rendering system for creating 3D graphics using raymarching in WebGL fragment shaders. The system supports multiple input formats that compile to GLSL.

JSON Format

Declarative scene description in JSON. Best for serialization, interchange, and programmatic generation.

.sdf.json files

DSL Format

Human-friendly text DSL for rapid prototyping and manual scene authoring.

sphere(r:1.0)

GLSL Output

Generated shader code compiled by WebGL. Uses g_df_scene(vec3 p) as entry point.

JSON Scene Format

Top-Level Structure

{
  "version": "1.0",
  "defs": {
    "myTemplate": { /* reusable node definition */ }
  },
  "root": { /* main scene node */ }
}

Node Types

Type Description Key Properties
sphere SDF sphere primitive params.r (radius), params.color
box SDF box primitive params.size (vec3)
torus SDF torus primitive params.major, params.minor
cylinder SDF cylinder primitive params.h (height), params.r (radius)
union CSG union of children children array
subtract CSG subtraction children (first - rest)
intersect CSG intersection children array
smoothUnion Smooth blend union children, k (smoothness)
transform Position/rotate/scale wrapper transform, child
material Color override wrapper params.color, child
ref Reference to a defs template id (name of def)

Value Types

// Constant number
1.0

// Array (for vec2, vec3, vec4)
[0.4, 0.8, 1.0]

// Variable reference (becomes uniform)
{ "var": "time" }

// Expression tree
{
  "expr": "add",
  "args": [
    1.0,
    { "expr": "mul", "args": [0.3, { "expr": "sin", "args": [{ "var": "time" }] }] }
  ]
}

Transform System

{
  "transform": {
    "translate": [x, y, z],       // Translation in world units
    "rotate": [rx, ry, rz],       // Euler angles in DEGREES, XYZ order
    "rotateQ": [x, y, z, w],      // Quaternion (glTF convention)
    "rotateAxis": {               // Axis-angle rotation
      "axis": [x, y, z],          // Normalized axis vector
      "angle": 45                 // Angle in DEGREES
    },
    "scale": [1, 1, 1]            // TODO: not yet implemented
  }
}

Rotation Conventions

PropertyFormatUnitsNotes
rotate [rx, ry, rz] Degrees Euler angles, applied in XYZ order (X first, then Y, then Z). Matches Blender/Three.js default.
rotateQ [x, y, z, w] — Unit quaternion (glTF convention). Avoids gimbal lock. Use for complex rotations or interpolation.
rotateAxis {axis, angle} Degrees Rotate around arbitrary axis. Intuitive for single-axis rotations.

Priority: If multiple rotation properties are present, rotateQ takes precedence, then rotateAxis, then rotate.

Notes Field

Any node can include a "notes" field for documentation. It is ignored by the renderer:

{
  "type": "sphere",
  "notes": "This is the player's head - adjust radius for different characters",
  "params": { "r": 0.5, "color": [1, 0.8, 0.6] }
}

Template System (defs/ref)

The defs system enables reusable components. Define a shape once, reference it many times with different transforms or materials.

{
  "version": "1.0",
  "defs": {
    "invader": {
      "type": "subtract",
      "children": [
        { "type": "box", "params": { "size": [0.5, 0.4, 0.3] } },
        { "type": "sphere", "params": { "r": 0.1 }, "transform": { "translate": [-0.12, 0.08, 0.2] } },
        { "type": "sphere", "params": { "r": 0.1 }, "transform": { "translate": [0.12, 0.08, 0.2] } }
      ]
    }
  },
  "root": {
    "type": "union",
    "children": [
      {
        "type": "material",
        "params": { "color": [0.0, 1.0, 0.5] },
        "child": {
          "type": "transform",
          "transform": { "translate": [-1.5, 0.6, 0.0] },
          "child": { "type": "ref", "id": "invader" }
        }
      },
      {
        "type": "material",
        "params": { "color": [1.0, 0.3, 0.8] },
        "child": {
          "type": "transform",
          "transform": { "translate": [1.5, -0.6, 0.0] },
          "child": { "type": "ref", "id": "invader" }
        }
      }
    ]
  }
}

Usage Examples

Loading a JSON Scene Programmatically

import { SimpleRaymarcher } from './ui/raymarcher.js';
import { loadJsonScene } from './core/json-loader.js';
import { generateGlslFromJson } from './core/json-codegen.js';

const canvas = document.getElementById('canvas');
const renderer = new SimpleRaymarcher(canvas);

// Load JSON scene
const json = await fetch('invader.sdf.json').then(r => r.json());
const scene = loadJsonScene(json);
const glsl = generateGlslFromJson(scene);

// Render
renderer.updateScene(glsl);

function animate() {
  renderer.render();
  requestAnimationFrame(animate);
}
animate();

Design Considerations

Mobile First

  • Touch-friendly controls with large tap targets
  • Responsive layouts that work on small screens
  • WebKit/iOS compatible (tested on Safari)
  • Performance-conscious shader complexity

Future: WebGPU

  • Current implementation uses WebGL 2.0
  • Architecture designed for WebGPU migration
  • Shader generation layer abstracts GPU API

Legacy DSL Demos (demos.html)

The legacy demos.html file contains text DSL demos that showcase features unique to the DSL syntax. While the JSON format (in index.html) is now the primary scene definition format, these DSL concepts are worth noting:

DemoConceptJSON Equivalent
Space Invaders (Template) template invader(x, y, color): syntax defs/ref system with material wrapper
Animated Invaders (Instance-Level) Passing sin(time) to template parameters Expression trees in ref transforms
Animated Invaders (Template-Level) sin(time) inside template definition Expressions inside def node params
Capsule Chain Multiple connected segments with smooth blending Already implemented in JSON demos
Rotating Torus Circular orbit using sin/cos Expression-based translate transforms

The DSL's template keyword compiles to GLSL functions when used 2+ times, reducing shader code size. The JSON system achieves similar optimization through the defs mechanism.
